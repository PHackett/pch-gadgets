# pch-gadgets
Automatically exported from code.google.com/p/pch-gadgets

This is the data & code to render the match results for my cricket club - Twyford & Ruscombe Cricket CLub (TRCC).

## Folder glossary

- `images/` - Images used by the project.
- `pch-gadgets/TestGadgets/` - Test gadget definitions and related files.
- `pch-gadgets/TRCC/` - The cricket club's scorecards, statistics, and gadgets.
- `pch-gadgets/TRCC/css/` - Stylesheets for TRCC pages and gadgets.
- `pch-gadgets/TRCC/data/` - Input and stored data used to render TRCC content.
- `pch-gadgets/TRCC/data/DataInput/` - Browser-based forms and controls for entering match data.
- `pch-gadgets/TRCC/data/fixtures/` - Match fixture and result XML, organized into a folder for each season.
- `pch-gadgets/TRCC/data/players/` - Player data and generated player statistics.
- `pch-gadgets/TRCC/data/players/GeneratePlayerStats/` - Source for the player-stat generation program.
- `pch-gadgets/TRCC/data/players/GeneratePlayerStats/src/` - Java source files for that program.
- `pch-gadgets/TRCC/data/sponsors/` - Sponsor data.
- `pch-gadgets/TRCC/gadgets/` - XML definitions for the TRCC gadgets.
- `pch-gadgets/TRCC/images/` - TRCC-specific images, including sponsor images.
- `pch-gadgets/TRCC/images/sponsors/` - Sponsor logos and images.
- `pch-gadgets/TRCC/objects/` - JavaScript objects for match, player, and statistics data.
- `pch-gadgets/TRCC/utils/` - TRCC utilities, including the [Play-Cricket result converter guide](pch-gadgets/TRCC/utils/README.md).
- `pch-gadgets/utils/` - Shared gadget framework and helper scripts.
